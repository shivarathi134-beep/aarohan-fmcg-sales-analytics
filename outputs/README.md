# Generated analysis outputs

Run `python python/aarohan_analysis.py` to regenerate these CSVs. `analysis_detail.csv` is the full analytical detail with descriptive columns and calculated metrics; `fact_orders_clean.csv` is the fact input prepared for Power BI. Summary CSVs answer the named dimensions. `executive_summary.csv` and `kpi_summary.json` are the main reconciliation references. These metrics are from synthetic data; profit and return values are estimates. Check `docs/Validation_Status.md` for execution boundaries.
